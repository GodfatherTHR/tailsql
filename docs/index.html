Table editor

Edit data without writing SQL.

The table editor keeps everyday changes in one place. The schema tree stays on the left, the grid stays on the right, and every write goes through a validated SQL statement.

  • Primary-key aware edits. Update and delete identify a single row.
  • Pagination and sorting. Choose 25, 50, or 100 rows per page.
  • NULL and default controls. Omit a value to let H2 supply the default.
  • Safe column handling. Identity, generated, and view columns are treated correctly.
  • No silent truncation. Values above the display cap are never saved back by accident.

Sharing

From loopback to tailnet to the public internet.

H2 always binds to 127.0.0.1. HySQL adds sharing only when you turn it on, and each step is a separate choice.

Local 127.0.0.1:9093

The H2 engine stays on loopback. Local work needs no network setup.

→
Tailnet 100.x.y.z:19093

A proxy on the Tailscale interface for peers allowed by your ACLs.

→
Public internet node.tailnet.ts.net:10000

Tailscale Funnel exposes the raw H2 TCP port to anyone on the internet.

Funnel is public. Raw Funnel TCP is not encrypted in transit, and the H2 password is the only access control. Use a strong password, share only what you intend to share, and disable Funnel when you are done.
  • Allowed ports only. Funnel uses 443, 8443, or 10000. Port 10000 is the default.
  • Cleanup on normal actions. Hosting is removed when the database stops, restarts, is deleted, or the app exits cleanly.
  • Crash reconciliation. A leftover Funnel mapping is checked on the next launch.
  • Independent choices. Tailnet hosting and public Funnel can be enabled separately.

Quick start

From download to first query in three steps.

Install HySQL

Download the Windows setup, run it, and launch HySQL. Java 11 or newer is required, and the H2 engine is included.

Create a database

Pick a name and a password. HySQL starts a loopback H2 server on the next free port and stores the database under ~/.hysql.

Edit, query, share

Open the Table Editor, run SQL, or enable Tailscale hosting when you need remote access. The docs cover every screen.

Get HySQL 0.3.0 for Windows.

The installer includes the H2 engine. Tailscale is optional, and your databases stay on your machine.
